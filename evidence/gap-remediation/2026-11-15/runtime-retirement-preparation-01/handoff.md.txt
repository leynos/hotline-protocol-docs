Donors retained: `state/mac-runtime/{hotline22-recovery,native-board-02}`
`base.dsk` and `rom`. Their live `working.dsk` files were never read.

Every entry has dev/inode/size/mode/mtime and a file SHA-256. The candidate
deletion set is exactly the four old roots; all other paths survive. There is
no authorized deletion in this packet.

For all 12 candidate disk/ROM files and four donor files, the collector ran
`sudo -n fuser -v PATH` immediately before hashing and required exit 1 with
empty output. It checked inode, link count and metadata before/after reading.

`sudo -n lsof +D` on the four old roots returned 1/no open files, with only
FUSE portal `can't stat` warnings; this is not a global process absence proof.
Parent A192 owns broader FD/cwd/image-owner census. No `oracle.lock` was held.
