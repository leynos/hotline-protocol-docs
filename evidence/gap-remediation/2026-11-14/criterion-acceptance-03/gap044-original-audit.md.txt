# A51: GAP-044 original-criterion audit (read only)

Frozen register `evidence/protocol-gap-analysis/2026-11-12/initial-gap-register.json`
GAP-044 asks which fields identify user messages, server/admin notices,
refusals and kick notices, and whether UID/name/options are mandatory by
variant. Closure: “Define discriminators and per-variant required/optional
fields, with fixtures for each known producer.” This is a **known-producer**
inventory, not proof that no further producer exists.

`notification-104-variants.md` already distinguishes the three observed wire
shapes: identity-bearing 103/102/113/101 with optional quote 214 on routed
108; 109=`0001` plus 101 for chat denial and 349 collision; and 101-only
for deletion/kick/console/configured-ban notices. Sender identity is not
universal: original PM identifies sender, generated feedback identifies the
responding recipient/invitee. Option 113 is branch-specific, not mandatory.
The same 109 shape cannot distinguish denial from collision; 101-only cannot
distinguish deletion, kick, console or configured application. Text is not a
universal discriminator, since an operator may send generated notice wording.
Request context, target/administrator socket and teardown can identify a
*frozen capture* but are not additional 104 fields. Notification type 104 is
sent by e.g. `FUN_10058ca0(target,0x68,buffer)`; this is unrelated to TLV
field 104, the icon in 107/121/304 and roster/presence records. Console
fanout (`10005510`) may distribute the prepared 104; that alias is not a
new unique schema.

Source `native-login-extras-01/oracle-queries/LX-D-10006590.c` builds field
101 via `FUN_10056ae0(...,0x65,...)` and sends transaction type 104 via
`FUN_10058ca0(...,0x68,...)` to each matched session, then requests close.
`batch-17/queries/B17-D-100023a0.c` supplies the configured-list apply
context. `D-10015e70.c` independently uses the same `0x68` send function for
kick options. The matching 42-byte text and 101-only shape do **not** let a
receiver distinguish configured apply from an option-2 kick on wire alone.
Expiry, protection and restart behavior belong to GAP-074, not this schema
criterion.

**Disposition:** If C69 publishes and verifies a paired configured-apply
capture with the reported two 101-only pushes, the already-known producer
inventory has a positive fixture for every listed send branch and explicit
non-discriminability where schemas overlap. The frozen criterion then appears
met at known-producer/branch scope. Before closure, update the inventory's
configured row and stale “fixture outstanding” paragraph, and qualify the
`10005f90` live-replacement branch rather than silently dropping it. Do not
claim all text/field origins are uniquely decidable or that no other producer
can exist. Parent owns paired review, inventory integration and status.
