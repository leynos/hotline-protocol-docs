Proposal only. No B74/B75 native case has run. Frozen implementation: protocol docs `native-liveness-preparation.md`, `scripts/native_liveness_cases.py`, `native_liveness_control.py`, `test_native_liveness.py` at imported docs head `d5d936e` (recheck exact full head/source hashes when freezing). Original criteria: GAP-005 asks for handshake/login/agreement/idle/partial-frame deadlines, reset traffic, units/config/close outcomes; GAP-036 asks which normal EOF, timeout, kick and failure paths emit302 and how rooms/transfers/IDs are cleaned up. This finite case can support only a slice.

- The exact prepared `plan.json`/`source-hashes.json`, runtime JSON, capture receipt, runner argv and unit definition, original 18-action preflight/postflight plans/reports/checksums, coordinator `plan.json`/`report.json` including **failed** reports, and unmodified controller stdout/stderr/exit if saved. Include action source+actual operation map, monotonic/UTC times, raw events, complete received/sent streams, decoded frames, unparsed suffixes, 135s window marker, per-flow window/final outcomes and source digests. No generic `verify_capture` claim for the custom report.

## Portable replay gates

1. File inventory, sizes, schema, SHA-256 and frozen as-run source/plan identities. Replay `native_liveness_control.verify_report` with frozen modules: all generated sends, raw chunks, parsed frames, 26 numbered O500 ACKs, B107 ACK+known242-byte109, O300 B-absent/noB354 before partial121, failed F107, fixed operation times and event/window EOF/RST/noEOF classifications. A failed runner remains an invalid/partial case, not an accepted native result.
2. Independently read all three PCAPs using `scripts/pcap_tcp.py:read_packets`. It accepts classic microsecond Ethernet/IPv4 TCP, rejects truncation/IP fragments and does not decode IPv6; validate linktype/snaplen first. Require no primary SYN on monitored original ports and no unrelated lab-port SYN. Identify exactly **nine** namespace SYN lifetimes (preflight1, O/A/B/F/S35/S75/S1207, postflight1), bound each to a report `connect` local port and guest NAT view. Resolve port reuse by `pcap_tcp.lifetime` plus actual SYN sequence/time; abort ambiguous mappings rather than using a bare port. `direction`/`stream` reassemble each direction with overlap checks and no gaps. Compare namespace and guest byte streams per lifetime, then compare report sent/received bytes, including TRTP, partial A/B input and all server tails. Record FIN/RST packet indices/times separately: `stream` intentionally excludes RST payload, so retain that packet view and never call it an application byte. If PCAP has a post-close payload suffix not delivered to the runner, preserve and label it; do not silently trim it to make equality pass. A report/PCAP mismatch needs explicit classification and blocks an unqualified complete-byte claim.
3. Check all nine flow maps and pre/post control reports against actual 2-account/41-Files/242-byte agreement baseline and zero mutation actions; source `10070790` bit1 **OR** state6 and `10070610` disconnect are static context only. Verify 135s host-monotonic window, operation jitter <=5s late/5ms early and actual guest/host PCAP time bounds. Associate each EOF/RST/noEOF claim with raw event and TCP packet; distinguish runner client-close from native close. Require complete tail/capture-stop receipts and no hidden tenth connection. Check managed capture/lock/VM source identities and stopped named-fork receipts independently of report prose.
4. Meaningful offline faults for publication verifier: delete/duplicate a SYN lifetime; change one namespace/guest byte or one captured partial prefix; shift an operation outside timing tolerance; relabel EOF as noEOF; drop a tail/packet; add a primary SYN or recorder drop; mutate pre/post baseline or frozen source; swap a NAT port. Reject each without needing a VM. Reuse existing `verify_native_roster_overlap.py` inventory/source/identity/stream/terminal pattern and `pcap_tcp` functions, but do not copy its unconditional “two FIN and no RST” assertion: this liveness case explicitly permits observed native RST and bounded noEOF.
