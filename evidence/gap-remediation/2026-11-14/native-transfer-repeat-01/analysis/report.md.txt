The exact running-binary copy `state/mac-runtime/native-banlab-three-01/SheepShaver-9c943...` is an ELF with Build ID `aba93db757c1d291109e7af8b23d52700b5b9e53`, `.symtab` and DWARF `.debug_info/.debug_line`, and is not stripped. `nm -C` exposes `RAMBaseHost`, `RAMBase`, `ppc_cpu`, `powerpc_cpu::get_register(int)`, `powerpc_cpu::execute(unsigned int)`, and flight-recorder functions. Source anchors: `tools/macemu/SheepShaver/src/Unix/main_unix.cpp:191,909,926-954` maps guest RAM; `tools/macemu/SheepShaver/src/kpx_cpu/sheepshaver_glue.cpp:715,773,839-848,924` owns CPU and monitor hooks; `tools/macemu/SheepShaver/src/kpx_cpu/src/cpu/ppc/ppc-cpu.cpp:138-210` implements the ring log. Yet `scripts/build-sheepshaver:32-35` builds `--without-mon`, and `emul_ppc` wraps `start_log()` in `#if 0`; the current binary has no supported enabled monitor command or automatic PPC trace dump. The symbols make a later controlled instrumented or paused snapshot plausible, not available proof of live state. No attach, signal, RAM read, or rebuild occurred here.

**Proposed single decisive experiment, subject to a separate design/grant:** before another fixture run, map the guest RAM entry and callback addresses to the emulated host memory and choose a bounded observation mechanism with explicit scheduling-effect controls. During one identical full A7 transfer, record at the 98,304-byte boundary and after it: worker `1000c200` revisit count; entry `+0x14` advertised length, `+0x18` requested/enqueued bytes, `+0x1c` allowance; transport pending-list bytes and `OTSnd` acceptance; callback event `0x66` through `10071770`/`10028dc0`; guest PC around those sites. Tie each sample to the SYN-scoped PCAP and compare a completion run if available. If the worker is revisited but a gate rejects work, inspect that gate; if not revisited, inspect scheduler/callback delivery. C42 static send-path report names the fields and OpenTransport branch, but runtime branch selection and the caller/scheduler chain are not yet proven. A naked fourth lab with no state observation is not a decisive test.

No causal conclusion follows from matching 98,304-byte prefixes or from the changed display, frontend, startup timing, and dialogs. No ban option 2 evidence was produced in C35/C45.
