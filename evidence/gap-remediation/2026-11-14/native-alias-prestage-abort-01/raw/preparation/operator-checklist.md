# R03 clocked Finder prestage checklist (operator policy)

All actions require the single owned `:124` GUI, current actual PID and
fresh screenshots. This checklist supplies no coordinates or shortcut.
Start the clock from O/epoch-start.utc, not from the first Finder click.

- Before +270 seconds, confirm owned server app and Ethernet capture
  phase are ready. Use only the reviewed startup helper on this display.
  If an Aros saver obscures the view, use one recognized blank wake click
  and recheck the actual screen; do not assume mouse motion reset idle.
- Bring Finder forward through the visibly named application selector.
  Hide Others only if the actual menu shows that named command; use the
  held-menu down/move/up helper with a fresh screenshot before click.
  Close only identified obstructing owned windows with their visible
  close boxes. Never guess old coordinates or an OSX shortcut.
- Open the visibly named Unix volume and select the sole owned
  `m-alias54-target` DATA20 leaf. Keep the owned HFS Files parent visible
  with usable space for `m-alias54-only` to appear and be selected after
  case 205. If a fresh screenshot shows its identified grow control, a
  reviewed down/move/up may resize this window for presentation only.
  Do not alter Finder or server settings.
  Do not create an alias, copy, paste, Get Info or click the server UI
  during this prestage. Stop on unexpected menu state, duplicate target,
  unknown dialog or ambiguous ownership.
- If inspecting the File menu before the case, confirm the visible
  Make Alias entry and cancel the menu without invoking it. A missing
  or disabled entry ends this attempt. Do not test the action early.
- By +270, root reviews and fsyncs O/prestage/reviewed.json mode0600:
  same PID/start/ns and `:124`; Finder/Unix/target screenshots with full
  SHA256; positive Finder, Unix and HFS Files visibility; target selected;
  disk/capture receipt SHA256; alias_created false and no prompt. Missing
  review by +270 means no closed18 request and bounded retirement.
- After closed18, recheck the same sidecar hash and a fresh awake Finder
  view. Case START still requires >=390 seconds remaining under the
  original 720-second deadline. No timing extension or bypass follows a
  healthy prestage. Root reviews the actual six case screenshots and
  one separate read-only Original binding image if the case reaches it.
